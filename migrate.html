⚠ One-time schema migration

Converts existing data to the v2 schema: project members maps → members subcollections, notification field names → camelCase, pending invites → deterministic IDs. Run this once, after signing in as an account that is owner on every project you want migrated, before deploying the new firestore.rules (the old rules — or none at all — need to still be in place, since this script writes data the new rules don't fully understand yet as "yours"). Delete this file once done.
